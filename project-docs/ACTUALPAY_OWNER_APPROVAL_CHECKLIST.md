# ActualPay UK — Owner Approval Checklist

- [ ] Confirm `https://actualpay.co.uk/` is the final production domain.
- [ ] Approve the final stock photographs and their use on the website.
- [ ] Confirm image and video licence evidence is retained and appropriate for commercial use.
- [ ] Confirm business contact details, service claims, legal wording and compliance statements.
- [ ] Select and configure an approved form provider if enquiries must submit without opening the visitor's email application.
- [ ] Confirm form notification recipient(s) and test a real submission and delivery.
- [ ] Review the hero poster-to-video transition in a real browser at desktop width.
- [ ] Review mobile hero poster and responsive crops at the specified viewport widths.
- [ ] Run a fresh Lighthouse performance audit on the production candidate.
- [ ] Run accessibility checks including keyboard navigation, focus visibility and contrast.
- [ ] Verify sitemap, robots, canonical URLs and social previews against the live domain.
- [ ] Approve deployment and publish the `production/` directory as the GitHub Pages root.
- [ ] Re-test the live website after deployment.
